# Glossary

- **Hydra** — the university Slurm cluster; login node `hydra-login`, partitions `compute` / `debug`.
- **Grid** — `params/grid.csv`: one row per simulation (`row_id, r0, incubation_days,
  contact_scale, region, seed`), generated by `params/make_grid.R`.
- **Array task** — one element of `02_simulate`; `$SLURM_ARRAY_TASK_ID` = 0-based grid row index.
- **Array master id (`%A`)** — the job id shared by all tasks of one array; `%a` is the task index.
- **`afterok`** — dependency type: start only if the upstream job (all tasks, for an array)
  finished with exit code 0.
- **Throttle (`%100`)** — max concurrently running tasks of an array.
- **Scratch** — `/scratch/$USER/sim-study`: fast, not backed up, purged after 30 days.
- **SEIR** — susceptible → exposed → infectious → recovered compartment model, simulated
  stochastically on the synthetic contact network (`R/seir.R`).
- **Attack rate** — share of the population ever infected in a run; the main outcome.
- **Run** — one simulated epidemic for one grid row (`$SCRATCH/runs/<row_id>.parquet`).
